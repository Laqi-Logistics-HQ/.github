 # Laqi Logistics

  ### Practical WooCommerce plugins for everyday store operations.

  We build tools that help store owners spend less time managing orders and more time running their business. Our focus
  is straightforward: automate repetitive work, simplify bulk updates, and keep inventory manageable.

  ## What we build

  - **Laqi Order Status Workflows**
    Visual automation for order routing, follow-up, integrations, and controlled bulk actions.

  - **Laqi Unit Stock Manager**
    Shared inventory pools for products and variations sold in different units and package sizes.

  - **Laqi CSV Order Status Changer**
    Bulk order status updates from a CSV upload.

  - **Laqi Product Data Checks**
    Scan your catalogue for missing or inconsistent product data that can cause fulfilment problems.

  [Explore our plugins →](https://laqi-logistics.com/plugins/)

  ## How we build

  We build around WordPress and WooCommerce conventions, with attention to compatibility, clear interfaces, and
  maintainable code.

  Our plugins are GPL licensed. Support comes directly from the people who build them.
